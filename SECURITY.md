# Security Policy

## Reporting a Vulnerability

This is a solo project maintained for learning and exploration.

If you discover a security vulnerability in this project, please open a
[GitHub Issue](https://github.com/quantumudit/biodata-studio/issues) with as much
detail as possible. Mark the issue title with `[SECURITY]` so it stands out.

- Response time: Within 48 hours

Responsible disclosure is appreciated and I'll work to resolve issues promptly.
